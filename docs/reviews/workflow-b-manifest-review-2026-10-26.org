* What the manifest is

One row per attempt at one combo (location x model x target scenario x
year), appended by =util_apply_workflow_b_batch.R=. Status is =ok= (written),
=skip= (output already existed, not rewritten), =missing-ref= (no ssp245
burden file for that model), =missing-target= (no target-scenario burden
file) or =fail=. The final state of a combo is its latest row.
