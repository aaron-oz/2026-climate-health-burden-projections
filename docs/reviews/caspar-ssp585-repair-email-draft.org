Subject: ssp585 test: 119 old files need rerunning

Hi Caspar,

Thanks for the ssp585 test. Nearly everything checks out, but 119 of the
ssp585 result files were not made by this run. They were already on your
disk from an earlier test, so the run skipped them instead of recomputing.
They use the TMREL setting we replaced in August, which puts Colombia's
numbers roughly 10 % too low. Our QA report should have flagged this and
didn't; that check is fixed now.

The affected files:

| location     | model         | years     |
|--------------+---------------+-----------|
| Haiti (114)  | access-cm2    | 2022-2040 |
| Colombia (125) | access-cm2  | 2022-2050 |
| Colombia (125) | access-esm1-5 | 2022-2050 |

Please run the following from the repo folder, in this order. It should
take about 2 to 2.5 hours, almost all of it in step 2 (estimate from your
run's timings).

1. Get the fixed QA check:

#+begin_src bash
git pull --ff-only origin main
#+end_src

2. Recompute the 119 files:

#+begin_src bash
Rscript global-scripts/util_run_global.R --location_id=114 --scenarios=ssp585 --models=access-cm2-r1i1p1f1 --years=2022-2040 --force_burden=TRUE
Rscript global-scripts/util_run_global.R --location_id=125 --scenarios=ssp585 --models=access-cm2-r1i1p1f1 --years=2022-2050 --force_burden=TRUE
Rscript global-scripts/util_run_global.R --location_id=125 --scenarios=ssp585 --models=access-esm1-5-r1i1p1f1 --years=2022-2050 --force_burden=TRUE
Rscript global-scripts/util_run_global.R --location_id=125 --scenarios=ssp585 --models=bcc-csm2-mr-r1i1p1f1 --years=2022-2036 --force_burden=TRUE
Rscript global-scripts/util_run_global.R --location_id=145 --scenarios=ssp585 --models=access-cm2-r1i1p1f1 --years=2022-2048 --force_burden=TRUE
#+end_src

3. Redo the scaling for the same files:

#+begin_src bash
Rscript global-scripts/util_apply_workflow_b_batch.R --location_id=114 --ref_scenario=ssp245 --target_scenarios=ssp585 --models=access-cm2-r1i1p1f1 --years=2022-2040 --force=TRUE
Rscript global-scripts/util_apply_workflow_b_batch.R --location_id=125 --ref_scenario=ssp245 --target_scenarios=ssp585 --models=access-cm2-r1i1p1f1,access-esm1-5-r1i1p1f1 --years=2022-2050 --force=TRUE
Rscript global-scripts/util_apply_workflow_b_batch.R --location_id=125 --ref_scenario=ssp245 --target_scenarios=ssp585 --models=bcc-csm2-mr-r1i1p1f1 --years=2022-2036 --force=TRUE
Rscript global-scripts/util_apply_workflow_b_batch.R --location_id=145 --ref_scenario=ssp245 --target_scenarios=ssp585 --models=access-cm2-r1i1p1f1 --years=2022-2048 --force=TRUE
#+end_src

   re-pack the bundle:
