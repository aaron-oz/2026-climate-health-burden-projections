Steps, from the repo root:

1. Update the repo:

   git pull

2. Re-run the summarizer with the date your run started. It reuses its
   cache, so it should take a few minutes:

   Rscript global-scripts/util_summarize_run.R --scenarios=ssp245 --jobs=16 --since=2026-09-16

   The QA report printed at the end now has a "Provenance" section. It
   should say FAIL for exactly those four combos, and the report ends
   with the commands to fix them, also saved as output/summary/fix_run.sh.
   Look at that file: it should rerun only locations 50, 89, 101 and 126
   (access-cm2, 2022). If it lists anything else, stop and send us
   output/summary/qa_report.txt.

3. Run it:

   bash output/summary/fix_run.sh

   It reruns the four combos one at a time (roughly two minutes each),
   clears those four locations from the summarizer's cache, and runs the
   summarizer again. The new QA report's Provenance section should say
   PASS on both lines, and fix_run.sh should no longer exist.

4. Re-export and send the bundle as before:

   Rscript global-scripts/util_export_review_bundle.R --scenarios=ssp245 --jobs=16
